7. UPLOAD DA FOTO DO UTILIZADOR
===============================

- O upload do avatar no Header foi unificado com a rota R2 existente.
- O AppShell deixou de tentar usar o bucket Supabase user-assets.
- O fluxo atual é:
  1. Enviar a imagem para /api/upload.
  2. Usar type=avatar.
  3. Receber publicUrl do R2.
  4. Guardar avatar_url no perfil.
- O limite atual do avatar é 2 MB.
- Formatos aceites: JPEG, PNG, WebP e GIF.
- Variáveis importantes:
  R2_ENDPOINT
  R2_ACCESS_KEY_ID
  R2_SECRET_ACCESS_KEY
  R2_BUCKET_NAME
  NEXT_PUBLIC_R2_PUBLIC_URL

11. GEMINI - TUTOR IA
=====================

Foi criada uma integração server-side com o Gemini.

Dependência instalada:
- @google/generative-ai

Rota criada:
- app/api/tutor/route.ts

Variáveis necessárias no .env.local:

  GEMINI_API_KEY=chave-do-gemini
  GEMINI_MODEL=gemini-3.5-flash-lite

A chave nunca deve ser colocada numa variável NEXT_PUBLIC_ nem exposta no frontend.

Fluxo:

  Interface do Tutor
        |
        v
  POST /api/tutor
        |
        v
  Gemini no backend
        |
        v
  Resposta para o painel

O Tutor IA recebe:
- Pergunta do estudante.
- Histórico da conversa.
- Disciplina atual.
- Capítulo atual.
- Tema atual.
- Conteúdos do capítulo.

O tutor foi instruído a:
- Responder em português.
- Ser natural, claro e objetivo.
- Começar diretamente pela resposta.
- Evitar saudações repetitivas.
- Usar respostas curtas e parágrafos pequenos.
- Usar Markdown quando for útil.
- Não inventar informação.
- Distinguir material interno de conhecimento geral.

O frontend renderiza Markdown básico:
- Títulos.
- Listas.
- Negrito.
- Código inline.
- Parágrafos separados.

Correção aplicada:
- O modelo antigo gemini-2.5-flash-lite deixou de estar disponível para novas contas.
- A rota passou a usar gemini-3.5-flash-lite por padrão e converte automaticamente o nome antigo.
- O histórico do Gemini não pode começar com uma mensagem model; mensagens iniciais desse tipo são removidas.

Teste realizado:
- POST /api/tutor devolveu HTTP 200.
- O Gemini respondeu corretamente a uma pergunta de teste.

13. LIMITES DO TUTOR IA
=======================

Limites atuais por utilizador autenticado:
- 20 perguntas por dia.
- 5 perguntas por minuto.
- 2.000 caracteres por pergunta.
- Até 3 áudios por pergunta.
- Até 8 MB por áudio.

A rota exige sessão autenticada.
Quando o limite é atingido, devolve HTTP 429 e uma mensagem clara.

Nota importante:
- O contador atual fica em memória no processo Node.
- Em Vercel/serverless, o limite deverá ser movido para uma tabela Supabase para funcionar corretamente entre instâncias.

15. AVALIACOES E SIMULADO INDIVIDUAL
====================================

A página Avaliações começou a ser transformada em Simulados.

O MVP atual inclui:
- Secção Simulado individual no topo.
- Seleção de disciplina.
- Seleção automática do próximo questionário pendente.
- Botão Começar prova.
- Reutilização do QuizPlayer existente.
- Histórico, repetição, revisão e estatísticas continuam disponíveis.
- Modal de quiz estabilizado ao mover ModalShell para fora do render.

Modo prova:
- A prova usa o tempo definido no quiz quando existe.
- Se não existir, usa 120 minutos por padrão.
- O cronómetro é controlado pelo QuizPlayer.
- O questionário é submetido quando o tempo termina.

Identificação das provas:
- O ano é procurado no título do quiz por uma expressão regular.
- Exemplos reconhecidos:
  Prova de Matemática I - 2025
  Exame de Contabilidade Geral - 2024
- A interface mostra Prova 2025 quando o título contém esse ano.

Para colocar uma prova no Supabase:

1. Criar um content do tipo quiz:

  insert into contents (
    chapter_id,
    topic_id,
    type,
    title,
    time_limit_seconds,
    order_index,
    is_active
  ) values (
    'ID_DO_CAPITULO',
    null,
    'quiz',
    'Prova de Matemática I - 2025',
    7200,
    1,
    true
  ) returning id;

2. Criar perguntas:

  insert into quiz_questions (
    content_id,
    question_text,
    order_index
  ) values (
    'ID_DA_PROVA',
    'Qual é o resultado de 2 + 2?',
    1
  ) returning id;

3. Criar respostas:

  insert into quiz_answers (
    question_id,
    answer_text,
    is_correct,
    order_index
  ) values
    ('ID_DA_PERGUNTA', '3', false, 1),
    ('ID_DA_PERGUNTA', '4', true, 2),
    ('ID_DA_PERGUNTA', '5', false, 3);

7200 segundos = 120 minutos.
